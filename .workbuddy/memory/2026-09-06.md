## 2026-09-06 19:15 手机访问 /gallery 无内容排查
- 用户反馈：电脑上传照片和文字后，手机打开网站仍显示“没有任何照片文字”。
- 根本原因：图片实际存储在 Supabase Storage `memory-photos` bucket，原 `schema.sql` 仅对数据库表开放公开 SELECT，未对 Storage 对象开放匿名读取，导致未登录用户无法加载图片。
- 修复：在 `supabase/schema.sql` 追加 `public_memory_photos_read` 策略，允许匿名用户 SELECT `memory-photos` bucket 的对象。
